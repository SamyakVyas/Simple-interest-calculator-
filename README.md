# Simple Interest Calculator

A simple interest calculator built in C++.

## Features
- Calculates simple interest based on principal, rate, and time
- Displays total amount after interest
- Input validation for invalid values
- Calculate multiple times in one session

## Formula
Simple Interest = (Principal x Rate x Time) / 100

## Concepts Used
- User input handling
- Mathematical formulas
- Loops and conditionals
- Input validation
